
# About

This repo contains some customizations to the official Prusa Buddy 3D camera that
comes with the Core One L.

## Disclaimer

!!! warning

    This project is not affiliated with Prusa in any way.

    All you see in this repo was coded with Anthropic Claude Opus 5.5 or newer.

    This code comes without any warranty, use at your own risk.

## Known limitations

- tested only with Prusa Buddy 3D camera that comes with the Core One L,
  it may work with other models, not tested
- tested with firmware cam-3.1.3
